#化学式 分子量計算プログラム 拡張版（README）
C++で作成されたコンソール向けの分子量・元素組成計算ツールです。括弧を含む化学式の構文解析、質量比率の算出、ファイル入出力に対応しています。

主な機能
分子量と元素組成の計算: 入力された化学式から分子量（g/mol、小数第4位表示）と、各元素の原子数・原子量・質量比率（%、小数第2位表示、降順ソート）を計算して表示します。

括弧・ネスト対応: Ca(OH)2 や Fe2(SO4)3、多重括弧などのグループ化と係数の乗算に対応しています。

3つの入力モード:

単一計算（1）: 1つの化学式を入力して即座に計算します。

一括入力（2）: 複数行にわたって化学式を入力し（空行で終了）、まとめて計算します。

ファイル読込（3）: テキストファイルから化学式を読み込み一括計算します（空行・空白のみの行・# で始まるコメント行は無視されます）。

レポート出力: 計算結果をテキストファイルへ保存できます。

約90種類の元素に対応: 水素（H）からフェルミウム（Fm）までの原子量データを内蔵しています。

ビルドと実行方法
C++11以降に対応したコンパイラでビルドしてください。

Bash
g++ -std=c++11 -O2 -Wall -Wextra main.cpp -o molar_mass
./molar_mass
使い方
プログラムを起動するとメニューが表示されます。番号を入力して操作します。

Plaintext
--- メニュー ---
1:単一計算  2:一括入力  3:ファイル読込  9:ヘルプ  0:終了
1: 化学式を1件入力します。

2: 1行に1つずつ化学式を入力し、何も入力せず Enter（空行）を押すと入力を終了します。

3: 入力ファイルのパスを指定して読み込みます。

9: プログラム内のヘルプを表示します。

0: プログラムを終了します。

計算を実行したあと、結果をファイルに保存するか（y / n）を選択できます。

入力例とファイル形式
化学式の例
H2O

NaCl

Ca(OH)2

Fe2(SO4)3

C6H12O6

読込ファイルの例（formulas.txt）
Plaintext
# 計算対象リスト
H2O
Ca(OH)2
  Fe2(SO4)3

C6H12O6
仕様・注意点
対応していない表記: 水和物のドット表記（例: CuSO4·5H2O や CuSO4.5H2O）、イオン電荷（例: SO4^2-、Na+）、0 以下の原子数や括弧の係数、100番台後半以降の超重元素（Md〜Og など）には対応していません。

一括保存の挙動: メニューの操作（1〜3）ごとに結果リストが初期化されるため、保存対象はその回の操作で計算した化学式となります。
